### [FileDrop](https://github.com/tuiop1/FileDrop)

**Secure File-Sharing Backend**

Backend service for securely uploading, storing, and sharing files through temporary download links.

**Highlights:**

* Modular monolith architecture with Spring Modulith
* Expiring download links and configurable download limits
* Secure management tokens
* Streaming file uploads and downloads
* Content validation with Apache Tika
* Malware scanning with ClamAV
* SHA-256 hashing and AES-GCM file encryption
* Transactional metadata management with PostgreSQL and Hibernate/JPA
* Automated expiration and cleanup workflows
* Unit and application-level testing with JUnit, Mockito, and Spring Boot
* AWS EC2 deployment with Amazon S3 object storage

**Stack:**
Java 21 · Spring Boot · Spring Modulith · Hibernate/JPA · PostgreSQL · AWS S3 · AWS EC2 · Docker · ClamAV · Apache Tika
